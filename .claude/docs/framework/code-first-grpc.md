# Xime Framework — Code-First gRPC

> Tóm tắt từ `grpc-codefirst.md` (framework). Tính năng đặc trưng của Xime.

## Mục tiêu
Nguồn chân lý duy nhất là **Python code** (Controller + DTO + type hint). Developer **không viết `.proto` thủ công**.

```text
Controller + DTO + type hint  (Python — nguồn chân lý)
   │  xime grpc generate
   ▼
ContractModel (IR)
   ├──► .proto             → Java/Go/Rust/C++ consume
   ├──► proto.lock.json    → cố định field number (ổn định binary)
   └──► Python servicer glue → GrpcAdapter phục vụ (Pydantic ↔ proto)
```
Hai mục tiêu: tránh lệch DTO↔proto; giảm boilerplate (chỉ viết DTO, không viết DTO+proto+stub song song). Code-first **sống cạnh** proto-first (`configure_grpc_services`) — `GrpcAdapter.start()` chạy cả hai.

## Khai báo
```python
class HashRequest(BaseModel):  file_id: str
class HashResponse(BaseModel): digest: str

class CryptoController:
    server_id = "public"
    @command("hash")
    async def hash(self, request: HashRequest) -> HashResponse: ...
```
Framework sinh `message HashRequest { string file_id = 1; }`, `message HashResponse { string digest = 1; }`, `service CryptoController { rpc Hash(HashRequest) returns (HashResponse); }`.

`@command` = unary. `@stream` → builder suy từ chữ ký: param `UploadStream` → CLIENT_STREAM (upload); param `DownloadStream` → SERVER_STREAM (download). Decorator dùng chung `core/contract/` với Socket Adapter (`ENDPOINT_ATTR="_xime_endpoint"`) → **một Controller, nhiều transport**.

## Field number stability — vấn đề cốt lõi
Protobuf định danh field bằng **số**, không bằng tên. Generate lại mà số đổi → phá vỡ tương thích nhị phân, lỗi âm thầm.

Giải pháp: **`proto.lock.json` (commit vào git)** ghi nhớ số field. Thuật toán `assign_numbers`: field cũ giữ nguyên số; field mới cấp số kế tiếp (tránh số reserved); field xóa → vào `reserved_numbers`/`reserved_names`, **không bao giờ tái dùng** → sinh `reserved 4; reserved "email";` trong proto.

## Type mapping (rút gọn)
`str→string`, `bytes→bytes`, `bool→bool`, `int→int64` (mặc định), `float→double`, `list[T]→repeated T`, `dict[K,V]→map<K,V>`, `Optional[T]→optional T`, `datetime→Timestamp`, `Decimal/UUID→string`, `IntEnum/StrEnum→enum`, nested `BaseModel→message`. Override số nguyên: `Annotated[int, ProtoInt32]`, `Annotated[int, ProtoUInt64]`. Kiểu không hỗ trợ → `UnsupportedTypeError` **lúc generate**.

## Streaming
- **Upload**: sinh chunk-wrapper `oneof { Req metadata=1; bytes chunk=2; }` (`rpc Encrypt(stream EncryptChunk) returns (...)`); server tách metadata → dựng Req, bơm chunk vào `UploadStream`. Business code không thấy wrapper.
- **Download**: `message DownloadChunk { bytes chunk = 1; }`, `rpc Download(Req) returns (stream DownloadChunk)`; mỗi `await download.write(b)` → yield chunk.

## Tổ chức proto theo `server_id`
`generated/{public,internal}/*.proto`; DTO dùng bởi ≥2 controller cùng `server_id` → `common.proto` (các file khác `import`). Header: `// Code generated by xime grpc generate. DO NOT EDIT.`

## CLI
- `xime grpc generate [--no-protoc]`: import `config/grpc.py` → scan controller → ContractModel (đọc/ghi lock) → ghi proto → (protoc) sinh `*_pb2.py`.
- `xime grpc check` (CI): so proto sẽ sinh với proto trên đĩa, exit ≠ 0 nếu drift (`Proto Out Of Date`).

## Cấu hình & serving
```python
# config/grpc.py
configure_grpc_codefirst(packages=["api.grpc"], output_dir="generated", lock_file="proto.lock.json")
```
`CodeFirstGrpcBuilder` đăng ký mỗi Controller với `grpc.aio.Server` qua handler động, marshalling Pydantic↔proto tại biên (business code thuần Pydantic). Generate là **bước build tường minh** (không generate runtime) → proto là artifact review/CI được.

## Lộ trình
`@proto_field(rename_from=, number=)`, bidi streaming, sinh SDK client đa ngôn ngữ, gRPC reflection/health tự động, map `Union → oneof`.
